# Vinnuferli

## Hópavinna og geymsla 

Í hópnum eru Björgvin Þeyr Guðmundsson og Konráð Jóel Jónasson, við skiptum upp verkefnunum í helminga og tókum hver sin hluta git repository er HBV301G_Verkefni_1. Við vorum báðir að pusha og gera pull request ad viðeigandi branch á main.

## Verkaskipting
- Við skiptum öllum kröfum í helming og geðum branch fyrir hverja kröfu t.d F-1,F-2 voru saman á branch og BRQ-1 var í sér branch.
- Ég bjó ti issue sem Björgvin tók að sér að gera gerði pull request og ég fór svo yfir það pull request og ef mér fannst það gott mergeaði ég því eða commentaði í issue til að laga. hann gerði hið sama fyrir mig.
- Gerðum pull á main gerðum svo branch frá main commit á því branch og push á main til að gera pull request.

## Ígrundun
- Í lok verkefnis gerið endurmat á verkefninu:
    - Samskipti voru mjög góð og reglu bundin notkun sem við gerðum í byrjun með að gera issue og pull requset gekk mjög vel.
    - Okkur fannst þetta verkefni ganga mjög vel fyrir sig mættum nota kanban borðið betur.

### Gagnsæisyfirlýsing um notkun gervigreindar

Ef þið notið gervigreind við vinnslu verkefnisins skal koma fram:

- Microsoft Copilot
- Dæmi um kvaðningu sem voru notuð: Getur þú sýnt mér template af því hvernig issue eiga að líta út?
- Gervigreind var notuð sem stuðningstæki við t.d mótun krafna samkvæmt Pohl & Rupp aðferðafræði og framsetningu GitHub Issues
- Tillögur frá gervigreind voru yfirfarnar og aðlagaðar að okkar verkefni ef átti við.

Við staðfestum að við höfum yfirfarið allt efni sem gervigreind lagði til, metið réttmæti þess og breytt eftir þörfum. Við berum ábyrgð á öllu efni sem skilað er í verkefninu.
