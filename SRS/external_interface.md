

# Ytri tenging (External interface)

Lýsing á tengingu milli hugbúnaðarkerfisins og notanda, annars hugbúnaðar, vélbúnaðar eða samskiptakerfis.


## UI-1

## 🔌 Skil
> Kerfið hefur samskipti við skýjalausn/bakenda sem sér um geymslu gagna, viðskiptarök og gagnagrunnssamskipti.

## 📥 Inntak / úttak
> Inntakið er JSON file sem sótt er úr cloudinu eða api. Úttakið verður fyrirspurnir um gögn ásamt uppfærðum gögnum í JSON filum. Breytingar geta gerst þegar starfsmenn nota kerfið.  

## 📚 Samskipti og staðlar
> Í gegnum vefsíðu þar sem allt er preloadað.

## 🔌 Skil

## 📥 Inntak / úttak

## 📚 Samskipti og staðlar
